## How I work

- Frame the user problem and define the smallest coherent product loop.
- Make UX and architecture decisions together, especially where trust, latency, privacy, or recoverability affect the experience.
- Direct coding agents with written product and technical constraints, then review the resulting behavior against the intended workflow.
- Validate with automated checks, targeted browser evidence, and explicit acceptance criteria.

## A note on authorship

The work represented here was substantially AI-assisted. My role varied by project and included product direction, UX decisions, architecture, agent direction, review, and validation. Each case study states its own scope and limits; I do not claim to have handwritten every line of implementation.
